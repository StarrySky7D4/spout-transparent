pub struct SpoutReceiver {
    selected: Option<SenderName>,
    current: Option<SenderInfo>,
    generation: u64,
}

impl SpoutReceiver {
    pub fn select(&mut self, sender: SenderName) {
        self.selected = Some(sender);
        self.current = None;
    }

    // 无来源时持续发现，不退出进程
    pub fn poll(&mut self) -> io::Result<bool>;
}

Targeted Fixes

两处体验问题，落到渲染时序解决。

不靠掩盖症状，而是缩短主线程阻塞并严格控制何时呈现 BackBuffer。

FRAME PACING

切换帧率后不再反复呈现旧帧。

只有真正渲染出新内容时才调用 Present，帧率档位切换通过可唤醒截止时间调度，避免旧 BackBuffer 造成虚影。

新纹理渲染完成Present
INPUT LATENCY

拖拽期间暂停同步 Alpha 回读。

窗口拖动时不再让 GPU→CPU 同步读取阻塞事件循环，指针输入可以优先完成；停止拖动后再恢复透明像素命中测试。
